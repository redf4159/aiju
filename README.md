## 是否需要先做人物图、场景图？

**建议顺序（与流程一致，略作细化）：**

1. **先完成文字**（当前包）：总纲 → 分集剧本 → 分镜 → 分镜 Prompt。  
   没有分镜，批量出图会反复返工。

2. **再做「资产层」**（在 ComfyUI 之前）：
   - **人物定妆（必做）**：见 `01_人物设定与出图Prompt.md`。  
     每个主要角色至少 1 张正面半身 + 1 张全身，固定 seed/LoRA/参考图，后续所有镜头引用同一套。
   - **场景概念图（建议做）**：见 `02_场景设定与出图Prompt.md`。  
     6～8 个主场景各 1～2 张空镜，分镜 Prompt 里写「场景参考：SC-xx」即可复用。
   - **道具/特效（可选）**：冰镜、幻术光效、彼岸花等，可在出分镜图时单独抽卡 1 张当参考。

3. **然后按集出分镜图**：`06_分镜Prompt/EPxx_prompts.md` → ComfyUI 工作流批量。

4. **图生视频 → 配音 → 剪辑**：按各分镜「时长」字段对齐。

**结论：** 不必在写剧本之前出图；应在 **分镜 Prompt 定稿后、ComfyUI 批量出图前**，优先完成 **主要人物定妆** 和 **核心场景空镜**。

## 中文短剧 vs 文件里的英文

**不会影响成片「说中文」**：观众听到的对白/旁白以 `04_分集剧本`、`07_图生视频单镜脚本` 里的**中文台词**为准，配音只认这些字段。

| 内容 | 语言 | 用途 |
|------|------|------|
| 剧本、分镜表、单镜台词 | **中文** | 配音、字幕、剪辑对轨 |
| `06_分镜Prompt` 画面描述 | 英文为主 + **新增中文列**（见各 EP） | ComfyUI / 即梦 / 通义等出图 |
| `07` 里「运动」 | 中英混合 | 图生视频；若平台只认中文，用同镜「画面」扩写即可 |
| 人名 Kasuo 等 | 英文音译 | 仅写在出图 Prompt 里，**不会出现在画面**（需加 `no text`） |

详细说明见 **`08_制作语言说明.md`**。若你**全程只用中文 Prompt 的工具链**，可以忽略英文列，只复制「中文画面 Prompt」。

## 制作参数建议（1分钟/集）

- 镜头数：8～12 镜/集  
- **单镜时长：建议 4～10 秒，硬性上限 15 秒**（超长必须拆镜，见 `07_图生视频单镜脚本/00_规范.md`）  
- 画幅：竖屏 9:16（短剧）或 16:9，全剧统一  
- 风格关键词：见 `01`、`02` 中 **STYLE_BASE**
