# 图生视频 · 单镜脚本规范

## 硬性约束

| 规则 | 说明 |
|------|------|
| **单镜时长** | **1～15 秒**（MiniMax H3 等不支持超过 15s 的单段） |
| **禁止** | 不得把多段台词合并成一条超过 15s 的视频任务 |
| **一镜一任务** | 每条 `07` 中的「镜头 xx」= 1 张分镜图 + 1 次图生视频 + 1 条配音轨片段 |
| **整集时长** | 约 60s = 多镜累加（通常 8～12 镜） |

## 单镜脚本字段

- **时长**：秒数，≤15  
- **静态画面**：给 ComfyUI 的关键帧内容（对齐 `06_分镜Prompt`）  
- **运动描述**：给图生视频（镜头运动 + 人物动作，宜短句）  
- **台词/旁白**：本镜内说完，超长则拆镜  
- **音效/BGM**：可选  

## 剪辑对齐

时间轴：`镜01[0-5s] + 镜02[5-11s] + …` = 本集成片。黑场镜可 1～2s 或直接在剪辑里做淡入淡出。
